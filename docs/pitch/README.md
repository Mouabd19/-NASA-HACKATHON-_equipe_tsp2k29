# Film du pitch (15 s)

`film_provisoire_fr.mp4` — version **provisoire** : 15 s, 1280×720, 30 images/s, légendes en français, sans son.

Déroulé : vaisseau et anneau à gravité artificielle → l'astronaute arrive du moyeu en apesanteur et se pose sur la
plateforme du scanner → descente dans la cuve, lecture tranche par tranche → sur l'ordinateur, les tranches deviennent
le corps 3D → l'application en plein écran (jour 94, alerte sur la hanche).

À savoir :
- Le scanner est une maquette simplifiée ; une version soignée du film (scanner fidèle, éclairage, étalonnage, 1080p) est en cours.
- Les tranches de scan affichées sur l'ordinateur sont ajoutées pour le film : l'application n'anime pas le scan.
- Les captures de l'application datent d'avant le renommage en TriFlow (ancien nom, ancien persona).
